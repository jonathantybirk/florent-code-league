# Florent Code League 2026

Bot for the [Florent Code League 2026](https://code.florent.vc/) — write a Python `Player` class that autonomously harvests titanium, builds logistics, and fights on a live Nordic leaderboard.

Tutorials: https://game.code.florent.vc/tutorials

## Setup

The game package currently supports CPython 3.12 and 3.13. This project pins
Python 3.13.14, the newest supported release:

```sh
uv sync
```

Run the game CLI through the project environment:

```sh
uv run fcode --help
```
