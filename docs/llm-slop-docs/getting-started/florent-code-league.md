# Florent Code League

Source: https://game.code.florent.vc/docs/florent-code-league

## Overview

**Florent Code League** is a competitive programming competition in which participants write Python bots to battle each other on a 2D grid map. Players control teams of units with the objective to destroy their opponent's Core base.

## How It Works

The competition follows a four-step process:

1. Participants implement a `Player` class in Python, with the engine invoking a `run()` method each turn.
2. Developers test locally using the `fcode` CLI tool and review replays.
3. Bots are submitted via `fcode submit` for ladder placement.
4. Teams advance by winning matches and accumulating rating.

## Core Gameplay

Matches occur on rectangular grid maps with the following characteristics:

- Each team begins with one stationary **Core** unit.
- **Builder Bots** are spawned to construct turrets, gather resources, and engage enemies.
- Matches conclude after 1000 rounds maximum.
- Victory occurs immediately upon destroying the opponent's Core.
- If both Cores survive, tiebreakers determine winners: titanium collected, harvester count, titanium stored, then coin flip.

**Titanium** serves as the sole resource, providing passive income every 4 rounds and generated by Harvesters placed on ore tiles.

## Competition Format

Matches are structured as best-of-five series, with results reflected on the leaderboard. Players may resubmit unlimited times, with each new submission replacing the previous ladder entry.
