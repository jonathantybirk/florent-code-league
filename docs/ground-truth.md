## READ THIS FIRST — what 2.3.3 changed

The 2.2.0 register was rewritten against a live 2.3.3 engine. Probe sources are in `bots/probes/`;
custom arenas are generated by the scratchpad's `mkarena.py`. Six claims are now **REFUTED**, and the
single most consequential change is the ammunition model.

| Was | Now |
|---|---|
| Per-turret ammo magazine, fed by conveyor | **Team-wide global ammo pool, filled only by the Core** |
| `get_ammo_amount` / `get_ammo_type` | **Gone.** Replaced by `get_global_ammo` / `convert_ammo` / `can_convert_ammo` |
| Builder action radius r²≤2, diagonals legal (G50) | **Orthogonal-only, never the own tile** |
| Builder cannot hit adjacent tiles (G13) | **Builder hits orthogonally adjacent tiles for 2 dmg / 2 Ti** |
| Builder range-0 own-tile sabotage shot (G14) | **Gone — `fire(own_pos)` raises** |
| Sentinel = 3-row 17-tile band (G15) | **Single-tile line, 5 tiles, r²≤32** |
| 15 maps | **21 maps** (new: bridge, jackpot, showdown, string, sweden, vase) |

**The `docs/` "correction vs. the official docs" about ammo was CORRECT for 2.2.0 and is WRONG for
2.3.3.** The official docs described the global pool all along; the repo re-wrote them to match a 2.2.0
engine that had per-turret ammo. That correction must be reverted — see the doc-errors list at the end.

### What G52–G57 mean for `bot/siege.py`

`bot/siege.py` ranks firing positions by **orthogonal adjacency to an ore tile**, so that a forward
Harvester can feed the Gunner with zero conveyors. **That constraint no longer does anything.** Ammo is
global and comes from the Core; a Gunner sited next to ore is in no way better supplied than one sited
in open ground. Firing positions should now be ranked on **line-of-fire to the enemy Core footprint,
walk distance from our spawn, and survivability** — nothing else. The ore-adjacency filter is now a
pure handicap: it discards most of the legal firing positions on every map for no benefit.

Gunner reach is small — attack r²=13 is **3 tiles** along the facing axis (`get_attackable_tiles` from a
Gunner returns exactly 3 tiles), so the Gunner must be placed within 3 tiles, in line, of a Core
footprint tile.
