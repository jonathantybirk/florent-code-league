## Chunk synthesis

Most load-bearing insights of 2026-07-28, with evidence:

1. **The 10 ms turn limit is a performance cliff, and CPU time is a first-class strategic resource.** On atoll seed 1: TLE 10 = totally inert bot (0 mined, 1 building, turn-1000 tiebreak); TLE 15 = Core kill turn 75; TLE ≥20 = Core kill turn 69 (session 6, parent's sweep, 19:32).
2. **Root cause of the cliff was algorithmic, not I/O:** `ordered_ores` ran one reverse BFS per ore; Core's round-0 strategy call cost 21.135 ms. One shared reverse BFS from the core perimeter is mathematically identical and cut it 21.7 ms → 2.76 ms; post-fix worst cases CORE 3.08 ms / BUILDER_BOT 6.67 ms / LAUNCHER 2.69 ms (session 6, 19:37–19:39). Three plausible-looking optimizations before it (lazy map load, O(1) map ID, entity-driven sensing) each changed nothing — the atoll result stayed byte-identical; parsing all 15 maps costs only ~1.15 ms.
3. **Map identification needs no evidence matching:** dimensions uniquely identify 12/15 maps; only the three 24x24 maps (quarry/runestone/vault) need a visible Core anchor — (2,2)/(20,20), (2,11)/(20,11), (2,19)/(20,3) respectively (session 6, 19:24 parent message; implemented and verified).
4. **Strategy-neutral code can still lose matches at the cliff:** the "clean mirror" challenger_2 — bots/1's exact strategy plus only the ordered_ores speedup — scored 7/30 vs bots/1 per session 8's prompt, yet 15/30 in session 9's batch 1 within the hour. Same pairing, same seed, wildly different totals; per-game determinism was separately confirmed (3 identical reruns). The unresolved implication is that TLE-10 outcomes are sensitive to machine load/conditions during benchmarking. **Open loose end.**
5. **First-listed side has a big fixed advantage:** claude bots won ~82–87% as first mover vs ~36–58% as second (c2: 36/45 vs 16/45); flipping argument order alone flips the duel result (125-titanium/56-turn win to the first-listed bot). Both orientations per pair are mandatory in any honest benchmark (session 9).
6. **Matches are deterministic at fixed seed** — three identical reruns of the same pairing (session 9, 21:11). Randomness only enters via the "Coinflip tiebreak" end condition label.
7. **The single most profitable strategic patch of the day was defensive completeness, not new offense:** claude_challenger_1 = 1v2 + `guard_core_conveyor()` always True + `use_path_aware_launch()` always True, nothing else — and it topped the 8-bot round robin at 145/210 (69%) (sessions 5 and 9). The celebrated supply-chain-hijack offense it "does well" is inherited Codex/1v2 code.
8. **Supply-chain hijacking is the meta's defining attack:** trace enemy Harvester→Core conveyors, replace the final conveyor with your own Gunner facing their Core, splitter on the penultimate belt, reinforce (session 9 description of the shared 1v2 codebase; countered by guarding the final tile, and later by Codex attacking the penultimate belt instead — session 6 prompt).
